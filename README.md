## Проекты

### 1. HR аналитика и предиктирование увольнений
- **Описание:** HR-аналитики компании «Работа с заботой» помогают бизнесу оптимизировать управление персоналом: бизнес предоставляет данные, а аналитики предлагают, как избежать финансовых потерь и оттока сотрудников. В этом HR-аналитикам пригодится машинное обучение, с помощью которого получится быстрее и точнее отвечать на вопросы бизнеса. построить модель, которая сможет предсказать уровень удовлетворённости сотрудника на основе данных заказчика. 
Почему бизнесу это важно: удовлетворённость работой напрямую влияет на отток сотрудников. А предсказание оттока — одна из важнейших задач HR-аналитиков. Внезапные увольнения несут в себе риски для компании, особенно если уходит важный сотрудник.
- **Навыки:** Предобработка данных, визуализация данных, EDA, предобработка перед обучением моделей, ML,подбор гиперпараметров, анализ важности признаков.
- **Инструменты:** Python, Pandas, Matplotlib, Seaborn, Shap, Sklearn, Optuna.

### 2. Анализ и предсказание покупательской активности
- **Описание:** В этом проекте нам удалось подобрать модель для предсказания упадка покупательской активности с большой долей правильных прогнозов. 
- **Навыки:** Машинное обучение, обработка данных, оценка модели, оценка важности признаков, сравнение моделей по качеству.
- **Инструменты:** Python, Scikit-learn, Pandas, Matplotlib.

### 3. CV определение возроста по фото
- **Описание:** Нужно построить модель, которая по фотографии определит приблизительный возраст человека. В нашем распоряжении набор фотографий людей с указанием возраста.
- **Навыки:** Глубокое обучение, обработка изображений, настройка гиперпараметров.
- **Инструменты:** Python, TensorFlow, Keras, Matplotlib, Сollections.

### 4. Анализ токсичности (NLP)
- **Описание:** В этом проекте я провел анализ текстовых отзывов клиентов для выявления основных тем и настроений.
- **Навыки:** Обработка естественного языка (NLP), анализ настроений, кластеризация.
- **Инструменты:** Python, NLTK, Scikit-learn, Pandas, Spacy, Catboost, LGBMClassifier, Transformers.
